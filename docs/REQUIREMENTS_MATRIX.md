# Assessment requirement matrix

| Assessment item | Local implementation / evidence | Scope or limitation |
| --- | --- | --- |
| Normal and malicious traffic | Reproducible episode generator plus offline capture adapter | Synthetic efficacy; no live/public benchmark claim |
| Port scan / reconnaissance | Fast, slow and mixed profiles; contextual rules and ensemble | Slower-than-window/distributed evasion unresolved |
| DoS / flooding | SYN/UDP/request profiles; contextual flood evidence | Backup ambiguity and unfamiliar workloads discussed |
| Additional attack | SSH/FTP/RDP-like brute-force profiles | Real outcomes require authentication logs |
| Meaningful feature extraction | Twenty-six behavioral/context/provenance features | Inputs, equations and rationales documented |
| Detection methodology | Calibrated RF/Extra Trees, contextual rules, novelty and prediction sets | Established methods; integration contribution |
| Explainability, severity and confidence | Per-event evidence trace, rule/model fields, queues and scores | No causal attribution or calibrated operational-risk claim |
| Runnable selectable prototype | CLI, Streamlit, CSV and offline PCAP/PCAPNG | No administrator/live-capture requirement |
| Evaluation and mistakes | Locked test, known historical diagnostics, ablation, intent challenge | All rows retained; negative results visible |
| Security/network considerations | DEPLOYMENT.md, MODEL_CARD.md and handbook | Throughput, capture quality, evasion, false positives and scaling |
| Mandatory benign baseline | Dashboard benign profile, 720 final rows | Honest discussion of remaining class errors/three security false alarms |
| Mandatory scan | Dashboard port_scan, 720 final rows | Full event evidence and review shown |
| Mandatory DoS / performance | Dashboard dos, 720 rows; nine-condition benchmark | Inference cost, not live victim impact |
| Mandatory additional attack | Dashboard brute_force, 720 rows | Outcome availability is shown |
| Mandatory ambiguous/missed case | Review/error filter plus historical/intent sources | Includes errors and information-theoretic ambiguity |
| Technical report 1,500-2,000 words | TECHNICAL_REPORT.md / rendered PDF | Approximately 1,677 source words |
| Complete concepts/documentation | WORKING_CONCEPT.md, data/model/deployment/research guides | All project concepts, limitations and interview prompts |
| GitHub repository / README / setup | Public source-first project, README, pinned requirements, CI | Build reconstructs large generated artifacts |
| Recorded 8-10 minute video | VIDEO_SCRIPT.md | Script supplied; recording remains a separate user-owned step |
| Individual work / AI usage | README and report disclosure | Candidate must understand and explain the work |

Publication does not imply that a demonstration video has already been recorded. The local prototype addresses the implementation/documentation requirements without claiming universal detection or novelty that has not been established.
